# Simulador Interactivo de Variables Macroeconómicas - Desafío Web I

Aplicación web modular construida bajo criterios semánticos e interactivos rígidos para la materia de Programación Web I, simulando problemas reales de logística, precios e inventario mediante lógica de código limpia en el lado del cliente.

## 🛠️ Tecnologías Aplicadas
- **HTML5 Estructural:** Uso extendido de selectores nativos semánticos.
- **CSS3 Responsivo:** Diseño líquido mediante cuadrículas (`Grid layout`) autoajustables basadas en Media Queries para dispositivos móviles y monitores de escritorio.
- **JavaScript & Detección Segura de Contexto:** Manipulación interactiva del Modelo de Objetos del Documento (`DOM`) a través de escuchadores dinámicos condicionales para evitar excepciones cruzadas de ejecución.

## 📐 Modelos Matemáticos Utilizados
1. **Modelo de Autonomía de Combustible:** Progresiones iterativas basadas en diferencias constantes por ciclo diario.
2. **Modelo de Tasas Inflacionarias:** Variaciones relativas porcentuales y análisis de costos integrales ponderados por cantidades de consumo.
3. **Análisis Logístico de Desvíos:** Ecuaciones diferenciales de distancias multiplicadas por factores operativos de costo y frecuencia.
4. **Análisis de Punto de Equilibrio Comercial:** Verificación lógica pos-estrés de mercado bajo coeficientes de demanda por pánico colectivo.

## 📂 Organización de la Entrega
- `index.html` a `index4.html`: Páginas de simulación interactiva por escenarios (A, B, C, D, E).
- `apart.html`: Banco de auditoría con los casos de estudio específicos de la guía práctica.
- `css/estilos.css`: Maquetación estética unificada de alto contraste.
- `js/script.js`: Motor analítico algorítmico del proyecto.
